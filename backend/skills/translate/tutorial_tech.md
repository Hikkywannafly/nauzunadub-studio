STYLE: Technical tutorial / coding screencast / tech review. Output
Vietnamese must be clear, patient, walking-through-the-code feel.

## Pronouns
- **mình / các bạn** — default for tutorial creator
- **chúng ta** — when stepping through code together ("chúng ta sẽ tạo...")
- Avoid **tôi** trừ khi tone trang trọng (talk hội thảo)

## KEEP English technical terms — DO NOT translate
API, function, variable, constant, parameter, argument, return,
class, method, instance, object, interface, type, generic,
deploy, build, compile, runtime, debug, log, console,
commit, branch, merge, pull request, repo, fork, rebase,
framework, library, dependency, package, install, import, export,
async, await, callback, promise, hook, component, props, state,
server, client, frontend, backend, database, query, endpoint, request, response,
container, image, microservice, monolith, serverless, lambda,
token, cookie, session, header, payload, schema, migration.

## Proper noun product/library names — KEEP nguyên
React, Vue, Angular, Next.js, Nuxt, Svelte, Tailwind, Bootstrap,
FastAPI, Flask, Django, Express, Spring,
PostgreSQL, MySQL, MongoDB, Redis, SQLite,
Docker, Kubernetes, AWS, GCP, Azure, Vercel, Netlify,
GitHub, GitLab, npm, pnpm, yarn, bun, uv, pip.

## Vietnamese tech vocab acceptable
- **thư viện** — library (khi nói chung)
- **gói** — package (đôi khi)
- **biến** — variable (in beginner context)
- **hàm** — function (in beginner context)
- **lỗi** — error / bug
- **chạy** — run
- **cài đặt** — install

Pattern: trong câu giải thích "what" → có thể dùng VN word, trong câu code-along "let's call this function" → giữ "function".

## Tone
- Clear, slow, patient
- "Ở đây mình sẽ..." → step-by-step
- Cho phép "ok", "ngon", "tới luôn" cho moment achievement
- Explain "why" lots — "lý do mình dùng async ở đây là..."

## Avoid
- Dịch tên thư viện sang tiếng Việt
- Quá nhanh — đây là tutorial, không phải demo
- Slang khó hiểu cho người mới
